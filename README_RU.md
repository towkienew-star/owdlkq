# Morph Studio — Fabric 1.21.4

Мод для записи роликов и локального изменения моделей игроков **без HUD, логотипов и водяных знаков**.

## Что есть

- `J` (можно переназначить в настройках Minecraft) — меню редактирования игроков.
- Список онлайн-игроков, включая тебя. Для каждого настраиваются `Overall`, `Height`, `Width`, `Head`, `Torso`, `Arms`, `Legs`.
- Кнопка **FAKE PLAYER**: создаёт локальную модель игрока перед тобой. **ЛКМ/ПКМ по манекену** открывает его редактор.
- 11 поз: Stand, T-pose, Folded arms, Wave, Dab, Point, Hands up, Sitting, Crouching, Look down, Dance.
- Манекен: размер каждой части, перенос перед камерой, удаление.
- Экипировка: готовые наборы брони + произвольный зарегистрированный предмет по `item ID` для головы, нагрудника, поножей, обуви, основной и второй руки.
- Скины: свой скин (`SELF`), скин любого игрока, **который сейчас присутствует в списке игроков сервера**, или собственный PNG-скин 64×64 из `config/morphstudio/skin.png`.
- Выбор модели PNG: Classic (широкие руки) или Slim.
- Сохранение размеров персонажей и параметров Fake Player в `.minecraft/config`.

## Как установить

1. Установи Fabric Loader 1.21.4 и Fabric API для 1.21.4.
2. Собери проект (ниже) и скопируй итоговый `morphstudio-1.21.4-1.0.0.jar` в `.minecraft/mods`.
3. Запусти профиль Fabric 1.21.4 и войди в мир.

## Как собрать .jar через GitHub, без локальной Java

1. Создай пустой репозиторий GitHub.
2. Загрузи **содержимое** этой папки, вместе с `.github/workflows/build.yml`, сохраняя вложенные директории.
3. `Actions` → `Build Morph Studio` → `Run workflow` (или дождись автосборки от push).
4. После зелёной галочки открой запись сборки → `Artifacts` → `MorphStudio-Fabric-1.21.4`.
5. Скачай ZIP артефакта, распакуй: внутри `.jar`.

Локальная сборка: JDK 21 и Gradle 8.13, `gradle build --no-daemon`.

## Важные ограничения

- **Только клиент**: на сервере у других игроков нет твоих визуальных изменений, хитбоксы и серверная логика не меняются.
- Fake Player не является настоящим игроком на сервере, не передаётся ему и исчезнет при выходе/смене мира. Параметры можно сохранить и создать заново.
- Копирование скина по нику работает только для онлайн-игроков (либо `SELF`); произвольный скин — PNG 64×64 в указанной папке. Профили Mojang по произвольному офлайн-нику не загружаются.
- Если клики по манекену мешают взаимодействию на сервере, для удаления есть кнопка `Fake Player -> Delete`.
- Модель локального игрока видна в третьем лице; руки первого лица в этом варианте не изменяются.
- В проекте нет телеметрии, отправки данных на сторонние сайты, HUD и вотермарок.
- Исходники подготовлены по API Minecraft 1.21.4, **не проверены полноценной сборкой и в игре**, потому что рабочая среда недоступна для скачивания Gradle/Fabric. Если GitHub показывает красный крестик, нужны строки ошибок компиляции.
